# Weather Forecast

**Live:** https://mentalplatypus.github.io/WeatherForecast/

A lightweight weather app for any place on Earth. Search by city, "City, Country", ZIP or postal code, landmark, street address, or coordinates (decimal or degrees), or use your current location.

For each place it shows the current temperature, feels-like, humidity, wind, UV index, air quality, precipitation, pressure, visibility and sunrise, plus an hourly chart for the next 24 hours and a 5-day forecast. Switch between °C and °F at any time.

Weather and air quality data from [Open-Meteo](https://open-meteo.com/). Place search by Open-Meteo geocoding and [Nominatim](https://nominatim.openstreetmap.org/), © OpenStreetMap contributors.
